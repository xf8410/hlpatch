## B：原调用保护 — 已实现局部回归，启用受 ABI 证据阻塞

- 不安装插件 TextCommon Hook，不自动安装屏幕镜像 Hook；不接管宿主原生崩溃信号，移除共享 setjmp/longjmp。

## C：大正文与存储预算 — 已接线，桌面回归通过

- metadata 保存有界预览；缓存导出、文件索引、局列表和派生事件导出按记录及 UTF-8 字节分页，显式游标。
- 完整原始正文先预留总字节额度再复制，通过后台队列落盘；游戏回调不持嗅探锁进行文件 IO。队列异常、拒绝和读取失败分别记证据。
- 请求只在压缩内容唯一匹配时关联。响应没有请求令牌，明确保持关联未知，删除没有消费方的旧响应头缓存。
- 新落盘原始文件带 SHA256，HTTP 分段读取最多 1 MiB；正常响应不再复制成“完整头加正文”字符串。日志只返回有界尾部预览，不改写历史日志。
- 派生 MessagePack 导出先按 file_id 筛选；输入最多 1 MiB、深度 32、节点 32768，输出受页预算约束。不按不可信声明长度预分配。
- 关闭恢复接口以外的旧实验性原生读写路由。允许的 HTTP 盘面入口只消费 worker 缓存。
- flush 暂停新采集，等待已接受任务；错误或缺口不报告完整成功，也不自动 resume。显式恢复不会清除历史缺口。

已经通过模块级与生产函数抽取测试，包括 1/16/64 MiB 已存文件流式核对、超限复制前拒绝、读取失败释放预算、队列失败/超时、SQLite 游标顺序、解码预算和缓存一致性。真实手机 PSS、帧时间和退出原因未验证。

`3.28.2-recovery.3` 继续修复发布层的锁范围：原 bridge 在共享状态锁内调用 `finish_summary`，仍会解析、深比较、复制整份观测，读取接口也在锁内深复制。现在 Publisher 由唯一采样 worker 持有，共享状态只交换不可变 Arc；转换、字段检查、HTTP/状态 JSON、深复制以及旧原始正文和旧快照的最终析构均在锁外。多字段发布仍在同一次短锁内完成，避免原始摘要和 envelope 来自不同采样。

确定性线程局部探针观察实际分配/释放并尝试取得状态锁，另按地址确认旧 raw 与旧 publication 的大缓冲各被真正释放一次；它不以运行时间替代锁范围证明。读取侧测试在停止 worker 后检查，采样侧仅用通道协调，避免把另一线程的正常短锁误判为当前线程持锁。

## D/E：采集实例、可靠推送与续养

SO 已接入单采样 worker。能力端点、V2 轮询及推送使用同一实例和不可变快照。相同盘面重复采样不换序号；没有当前观测时不伪造序号。HTTP 202 且身份完全匹配才记录收件 ACK；网络读写均有截止时间，失败保持待发送。

`.3` 同时修复 boot 恢复窗口：原实现进入 `booting` 后未撤销旧快照的可发送资格，恢复为 `capturing` 时可能在新采样完成前再次返回旧快照。现在进入 `booting` 就撤销该资格，新的观测完成后才重新开放 `/summary`、快照与推送。诊断用 `current()` 仍可检查历史；不会把它当作当前可发送盘面。用通道阻塞恢复采样可在旧实现复现失败，并在修复后证明三个对外入口均不暴露旧 A；A 的迟到 ACK 也不会确认新 B。

本轮三个新增 bridge 回归在旧源码上全部失败，原 10 项通过；修复后 bridge 13/13、portable 13/13 Release 通过，包括新增共享 Arc 去重身份测试。源码和生命周期另经独立只读复核。这些证明本地发布与重连机制，不证明作者现场空白文字、闪退或停止计算只有这些原因。

`3.28.2-recovery.2` 另修正旧摘要的错误校准声明：拉面的原始 `_totalTurnNum` 尚无真实样本证明可以直接作为累计回合，`/summary` 的派生 `turn/year` 因此返回 `null`，保留原始值、字段来源和未验证状态。V2 仅在 `display_summary.turn_observation` 保留这份证据，不将它导入正式回合或提高完整性。拉面旧 heuristic 返回结构化不可用；直接调用 evaluator 也返回错误，不补造评分。非拉面原行为通过修复前后的输出对照保留。

新增回归先在旧实现复现 2 项失败，再通过 4 项生产函数 Release 检查和 1 项 V2 契约测试。这一修复能消除错误的可信度声明，尚不能确定作者游戏显示异常或闪退的唯一原因。

公共运行层与 Android 已贯通显式选择实例、旧实例屏障、队列、JNI、局包 archive_seq 和 CSV 迁移。复盘按具体请求/配置决策行分段，取消行不制造运气基线；检查所有历史配置的引擎、数据、策略及模型版本。同实例跳过源序号时，完整当前盘面仍能计算，但重新建立运气起点并明确历史缺失。
