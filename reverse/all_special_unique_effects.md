## 统计

| 类别 | 数量 | 说明 |
|------|------|------|
| 无固有 (unique_effect_id=0) | 142 | R卡和部分SR |
| 标准固有 (type_0=1-19) | ~40 | SSR直接效果 |
| bond阈值 (type_0=101) | 174 | 最常见，普通彩圈 |
| 特殊条件 (type_0=30,102-122) | 44 | 卡片专属机制 |
| **总计** | ~400 | |

## 关键结论

1. **type 30** = 特殊标记，ハルウララ唯一使用
2. **type 102-122** = 21种不同的特殊触发条件，每种1-10张卡
3. **type 116** 最多（10张），可能是较通用的特殊条件
4. **type 118-122** = 友人卡专用（chara_id >= 9000）
5. **idle_mode_sub_rate** 非0 = 闲置（非得意训练）时也有副效果
6. 所有特殊条件的具体触发逻辑**不在 metadata 里**，硬编码在 SO 中
