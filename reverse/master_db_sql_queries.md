## 关键SQL查询

### 角色ID映射
```sql
SELECT id, name, rarity FROM chara_data ORDER BY id;
```

### 支援卡ID映射
```sql
SELECT id, name, rarity, support_card_type FROM support_card_data ORDER BY id;
```

### 同名不同卡
```sql
SELECT name, COUNT(*) cnt FROM chara_data GROUP BY name HAVING cnt > 1;
```

### 3-5星初始属性
```sql
SELECT chara_id, rarity, speed, stamina, power, guts, wisdom FROM chara_initial_status WHERE rarity >= 3;
```

### 支援卡加成
```sql
SELECT id, support_card_type, effect_type, effect_value FROM support_card_effect ORDER BY id;
```

### 技能数据
```sql
SELECT id, name, rarity, skill_type FROM skill_data ORDER BY id;
```

### 训练等级效果
```sql
SELECT command_id, level, gain_rate FROM single_mode_training_level ORDER BY command_id, level;
```

### 拉面杯地区
```sql
SELECT id, area_name FROM single_mode_14_area ORDER BY id;
```

### 拉面杯道具
```sql
SELECT id, item_name, effect_type, effect_value FROM single_mode_14_item ORDER BY id;
```

### 拉面杯食材
```sql
SELECT id, sozai_name, category FROM single_mode_14_sozai ORDER BY id;
```

### 拉面杯配方
```sql
SELECT id, recipe_name, required_sozai FROM single_mode_14_recipe ORDER BY id;
```

### 拉面杯试食会
```sql
SELECT id, tasting_name, condition FROM single_mode_14_tasting ORDER BY id;
```

### 拉面杯检查点
```sql
SELECT id, check_point_type, condition FROM single_mode_14_check_point ORDER BY id;
```

### 种田杯Enhance
```sql
SELECT id, group_type, level, effect FROM single_mode_13_enhance ORDER BY id;
```

### 青春杯Dream
```sql
SELECT id, dream_point, effect FROM single_mode_11_dream ORDER BY id;
```

### 目标比赛
```sql
SELECT id, race_name, race_grade, required_month FROM single_mode_target_race ORDER BY id;
```

### 赛后技能PT
```sql
SELECT race_id, skill_pt_reward FROM single_mode_race_reward ORDER BY race_id;
```

### 连续事件概率
```sql
SELECT event_id, probability FROM single_mode_continuous_event ORDER BY event_id;
```

### 乱入事件
```sql
SELECT event_id, probability, condition FROM single_mode_random_event ORDER BY event_id;
```

### 马娘加成
```sql
SELECT chara_id, bonus_type, bonus_value FROM chara_bonus ORDER BY chara_id;
```
