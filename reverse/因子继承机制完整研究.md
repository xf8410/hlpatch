## 二、因子保底机制 (育成完成时)

### 适性因子(赤因子)保底 — @shoppo_ura 实测

| 继承马娘合计★数 | 育成完成时获得该适性遗传子因子的概率 |
|:---:|:---:|
| 0-5个★ | 0% (无法获得) |
| **6-11个★** | **40%** |
| **12个★以上** | **100% (必出)** |

**规则:**
- 统计范围: 亲2人 + 祖父母4人 = 6匹种马
- 同一种适性因子(如英里)的★数求和
- 即使多个种马持有同一适性因子，概率不受影响(只看★总数)
- 这是**育成完成时**的因子获取，不同于**继承事件**中的因子发动

**示例:**
- 6匹种马里有4匹持有英里★3 = 12★ → 育成完成时**必出**英里遗传子因子
- 6匹种马里有2匹持有英里★3 = 6★ → 40%概率获得英里遗传子因子

## 三、继承事件概率 (育成中)

### 基础继承率 — Crazyfellow 实测

| 因子类型 | ★1 | ★2 | ★3 |
|---------|:---:|:---:|:---:|
| **青因子**(属性) | 70% | 80% | 90% |
| **赤因子**(适性) | 1% | 3% | 5% |
| **绿因子**(固有技能) | 5% | 10% | 15% |
| **白因子**(赛事) | 1% | 2% | 3% |
| **白因子**(其他) | 3% | 6% | 9% |

### 相性修正

```
实际概率 = 基础概率 × (1 + 相性值/100)
```

**示例:**
- 与亲的相性=30，亲持有★3白因子(技能)
- 基础概率 = 9%
- 实际概率 = 9% × (1 + 30/100) = 9% × 1.3 = **11.7%**

### 亲vs祖父母

- **亲(2匹)**: 全额概率
- **祖父母(4匹)**: 概率减半
- 青因子(属性)可能不减半(待验证)

### 继承时机

| 时机 | 内容 |
|------|------|
| 育成开始时 | 亲的绿因子(固有技能)确定继承；赤因子确定发动 |
| 经典级4月 | 继承事件1 — 从亲+祖6匹中随机继承因子 |
| 资深级4月 | 继承事件2 — 同上 |
| 育成完成时 | 因子获取(含保底机制) — 决定这只马娘自身的因子 |

## 四、白因子获取机制 — aoneko FANBOX 研究

### 基础概率

| 白因子类型 | 基础概率 |
|-----------|:---:|
| 技能白因子 | ~24% |
| 赛事白因子 | ~20% |
| 剧本白因子 | ~20% |

### 关键发现

1. **最低概率 = 20%**: 无论什么白因子，最低不低于20%
2. **技能白因子**: 每个已学技能有~24%概率变成白因子
3. **赛事影响**: 赛事胜利数增加 → 技能Pt增加 → 抽选次数增加 → 白因子变多(间接关系)
4. **青因子★数无关**: 青★3不会减少白因子获取(实测推翻了之前的猜测)
5. **白/金基础概率不同**: 白因子和金因子的基础概率有差异
6. **亲祖持有数影响**: 亲祖6匹中持有同一因子的人数越多，获取概率越高

## 五、继承树完整计算

### 继承树结构

```
        子
       / \
     亲1   亲2
    / \   / \
  祖1-1 祖1-2 祖2-1 祖2-2
```

### 相性值计算

6段2者间相性 + 4段3者间相性:
- 子←→亲1, 子←→亲2
- 亲1←→祖1-1, 亲1←→祖1-2
- 亲2←→祖2-1, 亲2←→祖2-2
- (3者间: 子←→亲1←→亲2, 亲1←→祖1-1←→祖1-2, 亲2←→祖2-1←→祖2-2, 子←→亲2←→祖2-2)

### 相性等级阈值

| 等级 | 累计相性值 |
|------|:---:|
| 1级 | 0-50pt |
| 2级 | 51-150pt |
| **3级** | **151+pt** |

3级相性 = 继承因子数量+质量大幅提升

### 相性值 = 共有关系性群组的点数之和

| 群组类型 | 点数 | 内容 |
|---------|:---:|------|
| 适性群组 | 7pt | 场地(芝/泥)/距离(短英中长)/跑法(逃先差追) |
| 游戏设定 | 2pt | 同室/同寮/同学年/友人/同班级 |
| 现实世界 | 1pt | 血统/血缁/生日/胜场/同期活跃 |
| 春乌拉拉特殊 | 8pt | 和任何马娘都8点 |

**注意**: 适性群组按马娘本身归属，不按卡片适性值。例: 美浦波旁短距离适性C，但仍属于短距离群组。

## 六、因子种类

### 因子颜色

| 颜色 | 类型 | 效果 |
|------|------|------|
| **青** | 属性因子 | 速度/耐力/力量/毅力/贤的+1或+2 |

## 八、实战建议

### 种马选择优先级

1. **适性因子保底**: 6匹种马里同一适性因子合计≥12★ → 必出该适性因子
2. **春乌拉拉万能**: 和任何马娘8点 → 种马最优选
3. **目白家七姐妹**: 互相高相性 → 累计相性值容易达3级
4. **G1冠军重叠**: 每个共有G1 +1pt → 选共通G1胜利多的种马
5. **同室/同寮**: +2pt → 比现实世界群组(1pt)更值

### 因子周回策略

1. 优先做**适性因子保底**(12★必出) → 确定性最高
2. 青★3继承率高达90% → 属性因子相对容易传
3. 白因子基础率仅3-9% → 需要大量周回
4. 绿因子(固有)亲确定继承 → 选对亲即可
